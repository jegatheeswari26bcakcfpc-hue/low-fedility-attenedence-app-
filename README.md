## 📌 Project Overview
The Student Attendance Management Dashboard is a user-friendly interface designed to manage student attendance and academic records. It provides attendance summaries, student profiles, class details, and analytics reports in one place.

## ✨ Features
- **Login Page:** Secure login using staff ID and password.
- **Attendance Dashboard:** Displays total students, present students, absent students, and late arrivals.
- **Today's Classes:** Shows class details and course status.
- **Student Profile:** Displays attendance rate, attendance breakdown, and recent history.
- **Analytics & Reports:** Provides weekly attendance charts, global average, and class performance reports.
- **Navigation:** Easy access to Dashboard, Attendance, Students, and Reports.

## 🎨 UI Design
- Clean and modern dashboard layout.
- Light grey and blue colour theme.
- Simple cards, charts, and tables.
- User-friendly navigation and readable typography.

The main goal of this project is to simplify attendance tracking, improve student record management, and present attendance information clearly through an intuitive dashboard.
